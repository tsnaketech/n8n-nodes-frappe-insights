# CLAUDE.md

All guidance for agents working in this repository lives in [AGENTS.md](AGENTS.md).
Read it before making any change — it is the single source of truth, and this file
is only a pointer to it.

This file deliberately carries **no summary** of `AGENTS.md`. The seven Frappe
packages ship this exact pointer, so a summary here would be one more copy to keep in
step — and the copies had already drifted: one of them still announced "the four
things not to guess" about its doctypes, next to an `AGENTS.md` listing eight. If
something is worth knowing before opening the code, it belongs in `AGENTS.md`, not
here.
